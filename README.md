# assuravia.ch

Site statique généré par `build.py` (Python, Jinja2, Markdown) et publié par Netlify.

- Générer en local : `pip install -r requirements.txt && python3 build.py`, puis ouvrir `dist/`.
- Les leads arrivent dans Netlify, onglet **Forms**.
- Pages publicitaires (Google Ads) : `/lp/rc-pro/`, `/lp/3e-pilier/`, `/lp/garantie-de-loyer/`.
